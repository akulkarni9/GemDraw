# Screenshots

Place README images here:

- `hld.png` — a high-level design (architecture) diagram
- `lld.png` — a low-level design (UML class) diagram from a drill-down

## How to capture

1. Generate an HLD (submit a prompt), then use the tldraw toolbar to **zoom to
   fit** so the whole diagram is visible.
2. Take a screenshot of the canvas (macOS: `Cmd+Shift+4`, then drag over the
   canvas) and save it here as `hld.png`.
3. Double-click a node to drill down and generate the **LLD** class diagram, then
   capture it the same way and save as `lld.png`.

Keep the filenames as above so the links in the root [README](../../README.md)
resolve.
